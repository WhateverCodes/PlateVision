# Development results - 20 September 2026

## Implemented
- Whole-plate CNN/GRU reader, CTC training, deterministic batch resume and bounded CPU sessions.
- Original and normalized-feature reader checkpoints retained in separate folders.
- Experimental reader, image-processing localization and explicit single-plate-crop options in the app.
- Conservative multi-threshold character segmentation selection: an alternative must pass the existing confidence threshold and format check; otherwise retain the original selection.
- Evaluation tools and integration/regression tests.

## Measured results
These are development checks, not final independent test scores.

The whole-plate normalized reader completed 15 epochs. Training loss fell to 1.133, but validation loss worsened after epoch 7; best validation loss was 2.668. Neither whole-plate version read any of the 15 validation plates exactly. The best-checkpoint character edit error rate was 78.17%. Do not present this reader as ready or keep training solely to reach a chosen epoch count.

On the same 15 crops, the existing character model read 2 exactly before confidence filtering. Conservative candidate selection raised that to 3. With the existing 0.75 minimum score and format gate, only 1 correct plate was accepted and no wrong plate was accepted in this small set. Other results were rejected. Most validation crops are very small; 14 of 15 are below 24 pixels high. This set is difficult and not representative of all image conditions, and it was used to choose the segmentation change.

Image-processing proposals overlapped 17 of 52 annotated plates at IoU >=0.5 on the 47-photo DataCluster development sample. This is candidate recall, not recognition accuracy or precision. Keep it experimental.

## Current state
The default app still uses the existing learned detector and character model, now with conservative alternative segmentation. The whole-plate reader is available only as an experimental option. Existing model weights and user reviews were not overwritten. All training sessions from this work have stopped and saved.

The separate 10 user photos and the 13-image internal test split were not used in this development comparison. They remain reserved. Automatic recognition is not yet reliable enough to call the project finished.

## Remaining work
Improve real-image recognition and localization, obtain a more balanced reviewed validation sample without modifying the reserved final tests, then perform end-to-end evaluation and package a demonstrated working model. Avoid broad accuracy claims from this 15-image development sample.

## Subsequent real-image adaptation
See REAL_IMAGE_ADAPTATION.md for newer results: the adapted character model improves raw exact readings to 5/15. Detector experiments did not improve operating-point detection and were not promoted.
